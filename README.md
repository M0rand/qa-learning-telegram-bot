# QA Learning Telegram Bot 🚀

Интерактивный Telegram-бот для изучения основ тестирования.

## 🔥 Возможности

- 📚 Интерактивные QA уроки
- 🏆 XP и уровни
- 🔥 Daily streak
- 🎤 QA Interview Mode
- 🏅 Achievements
- 🏆 Leaderboard
- 💾 SQLite database
- 🎮 Gamification

---

## 🧠 Чему учит бот

- Что такое баг
- QA vs Testing
- Severity/Priority
- Test Cases
- Smoke/Regression Testing
- Bug Reports
- Positive/Negative testing

---

## 🛠 Технологии

- Python
- aiogram 3
- SQLite
- Telegram Bot API

---

```bash
pip install aiogram
